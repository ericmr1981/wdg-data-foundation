# 数据概览页：品牌折叠 + 银行流水数据范围

## 状态

- Date: 2026-05-25
- Status: approved

## 目标

优化数据概览页 `ui/src/app/u/page.tsx`：
1. 按品牌折叠/展开
2. 银行流水显示数据范围和完整性

## 设计

### 交互

- 每个品牌卡片默认**折叠**，点击品牌标题行展开/折叠
- 右侧显示折叠图标（▼ 展开 / ▶ 折叠）

### 品牌折叠头

显示：品牌名 | 导入文件数 | 最近导入时间 | 折叠图标

### 展开内容：银行流水（门店级）

每行显示：

| 门店 | 数据范围 | 完整性 |
|------|---------|--------|
| 旗舰店 | 2024-01-15 ~ 2025-05-20 | 连续 |
| 二店 | 2024-01-10 ~ 2025-03-05 | 缺 5 天 |

- **数据范围**：最早 txn_time ~ 最近 txn_time
- **完整性**：与企迈数据一致，计算相邻 txn_time 日期差，缺失天数超过 0 则显示"缺 N 天"

缺口明细展示复用现有 `GapBadge` + `GapDetail` 组件（目前用于企迈数据），可迁移到组件区统一使用。

### 展开内容：企迈数据

保持现状不变（品牌级汇总 + 缺口展示）。

## 实现要点

- 折叠状态：React `useState` 管理，每个品牌独立
- 银行流水数据查询：扩展现有 per-store SQL，额外返回 min/max txn_time（需新增查询）
- 缺口计算：复用 `findGaps()` 函数
- GapBadge/GapDetail 组件位置：移到组件区，供银行流水和企迈数据共用
