# 手动匹配 & 规则管理页 — 用户使用故事

---

## 故事 1: 手工分类未识别流水

**用户:** 数据运营  
**场景:** 新导入银行流水后，部分流水未被规则引擎识别  
**操作流程:**
1. 进入 `/match`，默认显示未分类流水列表
2. 勾选需要分类的流水行
3. 用 QuickMatchButton 或批量匹配模态框选择分类
4. 可选择沉淀为规则 (沉淀时预览命中率)
5. 提交后触发重新匹配

---

## 故事 2: 添加新规则

**用户:** 系统管理员  
**场景:** 发现新的常出现的交易对手，需要创建对应分类规则  
**操作流程:**
1. 进入 `/rules` → 点击"新增"按钮
2. 选择 lvl1/lvl2 分类 → 选择匹配字段和关键词
3. 使用 match_value 预览功能查看预估命中数
4. 确认后创建规则 → 自动触发重新匹配

---

## 故事 3: 规则冲突排查

**用户:** 管理员  
**场景:** 发现同一笔流水可能匹配多条规则，需要修正优先级  
**操作流程:**
1. 在 `/match` 点击沉淀时系统检测到冲突
2. 冲突检测模态框列出冲突规则
3. 选择使用双条件匹配（AND）来缩小范围
4. 或回到 `/rules` 调整规则优先级（拖拽排序）

---

## 故事 4: 导入其他品牌规则

**用户:** 新品牌管理员  
**场景:** 新品牌上线，需要复用现有品牌的分类规则  
**操作流程:**
1. 进入 `/rules` → 点击"导入"按钮
2. 选择源品牌 → 选择 merge 或 append 模式
3. 确认导入 → 查看新增规则列表
4. 手动调整优先级后触发重新匹配
