# 数据上传 & 管道监控页 — 用户使用故事

---

## 故事 1: 上传银行对账单

**用户:** 运营/会计  
**场景:** 收到银行对账单文件后上传系统  
**操作流程:**
1. 选择品牌 (gelatomiiix)
2. 选择门店
3. 选择数据源 (银行对账单类型)
4. 选择文件 → 勾选"触发导入"
5. 提交 → 查看导入结果和覆盖率统计
6. 如有未分类数据，进入 `/match` 进行人工匹配

---

## 故事 2: 监控管道健康

**用户:** 系统管理员  
**场景:** 检查数据管道运行状态和覆盖率  
**操作流程:**
1. 进入 `/pipeline`
2. 查看软阀门KPI: 未分类数量和金额是否在可接受范围
3. 检查文件级覆盖率: 哪些文件尚未完成分类
4. 展开问题文件查看具体未分类流水
5. 查看管道运行记录确认是否有失败的步骤

---

## 故事 3: 排查未分类数据

**用户:** 数据运营  
**场景:** 某品牌未分类比例突然升高  
**操作流程:**
1. 在 pipeline KPI 看到 unclassified_pct 异常
2. 查看 Top 未分类关键词 → 识别是否有新对账对方未匹配
3. 进入 `/rules` 添加对应规则
4. 回到 `/pipeline` 触发重新匹配
