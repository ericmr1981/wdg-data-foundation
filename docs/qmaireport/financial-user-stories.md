# 财务报表页 — 用户使用故事

---

## 用户画像

| 角色 | 关注点 | 操作频率 |
|---|---|---|
| 财务总监 | 收入/利润/现金流趋势，门店整体健康状况 | 每月 |
| 会计 | 查看明细科目，核对银行流水与财务报表的一致性 | 月末对账 |
| 运营经理 | 店均营收，毛利率波动，费用控制 | 每周 |
| 老板 | 经营看板一眼看清全貌，快速链接进入详情 | 每日 |

---

## 故事 1: 月度利润查看

**用户:** 财务总监  
**场景:** 每月初查看上月利润表  
**操作流程:**
1. 进入 `/u/financial`，选「按月」+ 上月期间
2. 顶部 Overview 6个KPI卡片总览经营状况
3. 点击「利润表」Tab → 查看收入/支出各科目明细
4. 关注毛利率和净利润率变化

**涉及API:** `overview`, `profit`

---

## 故事 2: 现金流排查

**用户:** 财务  
**场景:** 发现经营性现金流为负，需要排查原因  
**操作流程:**
1. 切换到「现金流量表」Tab
2. 查看经营性/投资性/融资性三类活动的净额
3. 如经营性现金流为负，查看收入(REV_BIZ)和支出(HR/MATERIAL/RENT等)的对比
4. 切换到 `/u/payment` 查看具体付款对手方明细

**涉及API:** `cashflow`, `payment-metrics`, `counterparty`

---

## 故事 3: 费用结构分析

**用户:** 运营经理  
**场景:** 对比不同门店的费用结构  
**操作流程:**
1. 在 `/u/dashboard` 选择一个门店
2. 查看费用明细区块的可折叠列表
3. 对比物料成本、人工成本、房租水电等占比
4. 切换到另一门店，观察差异

**涉及API:** `overview`, `kpi-trend`

---

## 故事 4: 付款对手排查

**用户:** 会计  
**场景:** 查找某供应商的全部付款记录  
**操作流程:**
1. 进入 `/u/payment`
2. 在左栏搜索供应商名称
3. 选中后右侧展开全部流水明细
4. 核对金额、时间、摘要是否正确

**涉及API:** `counterparty`

---

## 故事 5: 经营看板每日巡检

**用户:** 老板  
**场景:** 每天打开看全局经营动态  
**操作流程:**
1. 进入 `/u/dashboard`
2. 顶部KPI卡片看到收入、毛利率、净利率、现金流
3. 点击感兴趣的指标 → 下方趋势图展开历史走势
4. 底部快速链接进入财务/POS/收入详情

**涉及API:** `overview`, `kpi-trend`, `qimai-revenue`

---

## 规范合规说明

所有 financial 页面 API 均符合数据使用规范：
- ✅ 银行数据来源：`bank_txn_classified_snapshot`（预分类快照）
- ✅ 无独立 `bank_rule_map` 模糊匹配
- ✅ 无自行调用 `fn_classify()`
- ✅ 口径统一：全站 financial API 同源同口径
