# Yufeng｜T2.1 分类体系枚举 v0

> 定义银行流量的 lvl1/lvl2 分类体系，明确「哪些属于营业收入、哪些属于往来/借款/注资/还款」。

---

## 1) lvl1 一级分类

| lvl1 | 说明 | 方向 | 归属 |
|------|------|------|------|
| 营业收入 | 第三方平台/支付公司回款、客户付款等 | in | **营业收入** |
| 手续费 | 银行/支付通道扣费 | out | 费用 |
| 税金 | 税务扣款（增值税等） | out | 费用 |
| 租金物业 | 房租、物业费、水电费 | out | 费用 |
| 人力 | 工资、社保、劳务派遣、人力服务费 | out | 费用 |
| 运费 | 货拉拉、同城配送、快递、闪送 | out | 费用 |
| 管理费用 | 办公、系统、差旅、维修、广告等 | out | 费用 |
| 材料采购 | 原材料、辅料、包装物料采购 | out | 费用 |
| 其他费用 | 无法归入上述类别的支出 | out | 费用 |
| 往来 | 股东借款、客户预付款、供应商往来款 | any | **往来/借款/注资/还款** |
| 借款 | 借入/借出款项 | any | **往来/借款/注资/还款** |
| 注资 | 股东增资、资本注入 | in | **往来/借款/注资/还款** |
| 还款 | 归还借款/贷款 | any | **往来/借款/注资/还款** |
| 其他收入 | 非营业性质的偶然收入 | in | **其他** |
| 其他支出 | 非营业性质的偶然支出 | out | **其他** |
| 未分类 | 尚未匹配到任何规则 | any | **待处理** |

## 3) 归属判定规则

### 3.1 营业收入 vs 往来/借款/注资/还款

| 归属 | 判断依据 |
|------|----------|
| **营业收入** | 对方单位为：第三方平台（美团/饿了么/抖音/京东）、支付公司（钱袋宝/财付通/支付宝/富友）、客户直汇（备注为货款/餐费/消费） |
| **往来/借款/注资/还款** | 对方单位为：股东个人、关联公司、备注含"借款"、"还款"、"注资"、"投资"、"预付"等关键词 |

### 3.2 费用类 lvl1 判定

| 方向 | 判断规则 |
|------|----------|
| in（收入） | lvl1 优先为「营业收入」；非营业性质收入用「其他收入」 |
| out（支出） | 根据摘要/附言/对方单位关键词匹配对应费用类别；若无法匹配，用「其他费用」 |

```
营业收入, 手续费, 税金, 租金物业, 人力, 运费, 管理费用, 材料采购,
```
