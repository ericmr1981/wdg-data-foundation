# Yufeng｜UI 交互原型 v0（人工匹配 + 规则管理）

> 目标：当覆盖率<100%，运营/财务可在 UI 里把未分类流水快速归类；同时可维护规则并即时看到覆盖率变化。
> 一期约束：无需登录；强调可操作性与批量效率。

## 1) 页面一：未分类流水（人工匹配主入口）
### 列表字段（默认展示）
- 交易时间 txn_time
- 对方单位 counterparty_name
- 摘要 summary
- 附言 memo
- 转入金额 in_amt / 转出金额 out_amt
- 当前分类：lvl1/lvl2（默认“未分类”）
- 推荐分类（可选展示）：候选 lvl1/lvl2 + 命中规则（如果有）

### 默认排序
- 未分类优先
- 金额（abs(in-out) 或 in/out）降序
- 时间倒序

### 筛选条件
- 月份（必选/默认最近月）
- 方向（in/out/全部）
- 对方单位关键词
- 摘要/附言关键词
- 金额区间
- 分类状态（未分类/已override/已规则命中）

### 操作
- 单条匹配：选择 lvl1/lvl2 → 保存（写入 override）
- 批量匹配：勾选多条 → 选择 lvl1/lvl2 → 保存
- 快捷批量：对“同对方单位”一键批量归类（可选）
- 撤销 override：恢复为规则/未分类

## 2) 页面二：规则管理（bank_rule_map）
### 列表字段
- enabled
- priority
- match_field / match_type / match_value
- direction
- lvl1 / lvl2
- note

### 操作
- 新增/编辑/启停/删除（软删）
- priority 上移/下移（或直接编辑数值）
- 规则测试：选择一条流水（或输入文本）→ 返回命中规则与分类结果

## 3) 页面三：覆盖率面板
- 选择月份
- 覆盖率：按笔数/按金额（规则命中 + override 命中）
- 未分类金额、未分类笔数
- 未分类 Top 对方单位（金额/笔数）
- 未分类 Top 关键词（从摘要/附言提取）

## 4) 一期“好用”的关键细节
- lvl1/lvl2 下拉需支持搜索
- 批量操作必须明显且可撤销
- 保存后列表即时刷新，覆盖率即时更新
- 所有写操作都写到 override（不改 ods）
