# WDG Data Foundation｜项目目录说明

## 目录结构
- `ProjectTasks.md`：任务进度卡（目标/验收/里程碑/拆解与状态）
- `Summary.md`：项目摘要（≤500字）
- `Readme.md`：本目录说明

## 使用方式
- 任何新增资料/方案/代码/截图等，请优先放在本项目目录下，并在 `ProjectTasks.md` 的任务项里挂上链接/路径，保证可追溯与可验收。
